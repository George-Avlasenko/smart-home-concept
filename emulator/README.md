# Эмулятор устройств Smart Home

Отдельный процесс, который раз в минуту отправляет показания датчиков и чайников в API (пользователь **demo**). Бэкенд обновляет показания, применяет авто-логику по диапазонам (кондиционер, увлажнитель, вентиляция, окно) и рассылает события по SSE.

## Запуск

1. Запустите API и БД (например, `docker-compose up -d db backend`).
2. В `appsettings.json` задайте:
   - **ApiBaseUrl** — базовый URL API (по умолчанию `http://localhost:5000`);
   - **DemoPassword** — пароль пользователя `demo` (по умолчанию `demo`);
   - **IntervalSeconds** — интервал отправки в секундах (по умолчанию 60);
   - **EmulationEnabled** — `true`/`false` для включения/выключения.
3. Выполните:
   ```bash
   cd emulator
   dotnet run
   ```
   Или из корня репозитория:
   ```bash
   dotnet run --project emulator/SmartHome.Emulator.csproj
   ```

При первом запуске эмулятор вызовет `POST /api/emulator/ensure-demo-house` и создаст дом «Демо-дом» с комнатами (Прихожая, Кухня, Гостиная, Спальня) и устройствами (датчики, свет, окна, кондиционер, увлажнитель, вентиляция, чайник). Далее раз в заданный интервал отправляет `POST /api/emulator/readings` с уличными и комнатными показаниями.

Переменные окружения переопределяют `appsettings.json` (например, `Emulator__DemoPassword`, `ApiBaseUrl`).
