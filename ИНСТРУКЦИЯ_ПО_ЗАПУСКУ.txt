ТРЕБОВАНИЯ:
-----------
- Docker и Docker Compose установлены
- PostgreSQL 15+ (если запускаете БД локально)
- .NET 9.0 SDK (если запускаете backend локально)
- Node.js 18+ и npm (если запускаете frontend локально)

================================================================================
ВАРИАНТ 1: ЗАПУСК ЧЕРЕЗ DOCKER
================================================================================

1. ПОДГОТОВКА БАЗЫ ДАННЫХ
   -----------------------
   docker-compose up -d db

2. ЗАПУСК BACKEND
   ---------------
      nohup dotnet run --project backend/SmartHome.API --urls "http://localhost:5000" &
   
   Backend будет доступен по адресу: http://localhost:5000
   Swagger UI: http://localhost:5000/swagger

3. ЗАПУСК FRONTEND
   ---------------
      cd frontend && npm install
      nohup sh -c "cd frontend && npm run dev" &
   
   Frontend будет доступен по адресу: http://localhost:5173

4. ОСТАНОВКА ПРИЛОЖЕНИЯ:

5. АВТОЗАПУСК ПРИ ВКЛЮЧЕНИИ ПК:
   - Контейнеры НЕ запускаются автоматически при загрузке системы
   - Для запуска используйте: docker-compose up -d
   - Для остановки: docker-compose down
   - Локальный backend: Ctrl+C в терминале
   - Локальный frontend: Ctrl+C в терминале

5. ОЧИСТКА ДАННЫХ:
   - Docker volumes: docker-compose down -v
   - Локальная БД: DROP DATABASE smarthome; CREATE DATABASE smarthome;
   - Локальная БД: DROP DATABASE smarthome; CREATE DATABASE smarthome;
