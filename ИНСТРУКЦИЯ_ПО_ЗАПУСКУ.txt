================================================================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОЕКТА "УМНЫЙ ДОМ"
================================================================================

Актуально для текущей структуры проекта:
- backend (ASP.NET Core 9, порт 5000)
- frontend (React + Vite + Nginx, порт 5173)
- db (PostgreSQL 15, порт 5432)
- tuya-service (FastAPI + TinyTuya, порт 5055 на хосте; в compose — network_mode: host на Linux, иначе UDP-автопоиск ламп в Wi‑Fi чаще всего пустой)


================================================================================
1) ТРЕБОВАНИЯ
================================================================================

- Docker + Docker Compose
- (для локального запуска без Docker):
  - .NET SDK 9.0+
  - Node.js 18+
  - Python 3.11/3.12


================================================================================
2) БЫСТРЫЙ ЗАПУСК ЧЕРЕЗ DOCKER COMPOSE (РЕКОМЕНДУЕТСЯ)
================================================================================

Из корня проекта:

  cd /home/user/Downloads/for_studying/kp
  docker-compose up -d --build

Проверка:

  docker-compose ps

Ожидаемые сервисы:
- smarthome_db
- smarthome_backend
- smarthome_frontend
- smarthome_tuya

Доступ:
- Frontend: http://localhost:5173
- Backend API: http://localhost:5000
- Swagger: http://localhost:5000/swagger
- Tuya service (прямой доступ): http://localhost:5055/health


================================================================================
3) ОСТАНОВКА / ПЕРЕЗАПУСК
================================================================================

Остановить всё:

  docker-compose down

Перезапустить только frontend и tuya-service:

  docker-compose up -d --build frontend tuya-service

Перезапустить только backend:

  docker-compose up -d --build backend


================================================================================
4) ЛОГИ КОНТЕЙНЕРОВ
================================================================================

  docker-compose logs -f frontend
  docker-compose logs -f backend
  docker-compose logs -f db
  docker-compose logs -f tuya-service


================================================================================
5) TUYA: ЧТО УЖЕ ИНТЕГРИРОВАНО
================================================================================

Маршрут в UI:
- /labs/tuya (пункт "Tuya (лампа)" в левом меню)

Что умеет страница:
- Проверка сервиса (/tuya/health)
- Статус устройства
- Вкл/выкл
- Яркость (ползунок, %)
- Температура (ползунок, 2700..6500K)
- Цвет HSV (ползунки)

Прокси:
- В Docker/Nginx: /tuya/* -> host.docker.internal:5055/* (tuya-service в network_mode: host)
- В dev (Vite): /tuya/* -> localhost:5055/*


================================================================================
6) ВАЖНО ПО БЕЗОПАСНОСТИ
================================================================================

Секреты Tuya (local key, API secret) нельзя хранить в git.

Если ключи уже где-то засвечены:
1. Перегенерируйте/перевыпустите их в Tuya IoT.
2. Обновите значения в UI/конфигах.

Примечание: сейчас на странице `frontend/src/pages/TuyaLightExperiment.tsx` есть
предзаполненные поля (device_id/local_key/ip) для быстрого теста. Перед
публикацией/передачей проекта это нужно убрать.

  cd /home/user/Downloads/for_studying/kp/frontend
  npm install
  npm run dev

   - PostgreSQL: 5432

   - Frontend: 5173

2. УЧЕТНЫЕ ДАННЫЕ БД (по умолчанию):

   - Пароль: password123
   - База данных: smarthome

3. УЧЕТНЫЕ ЗАПИСИ ПРИЛОЖЕНИЯ:
   - Есть пользователь demo

   - Локальный frontend: Ctrl+C в терминале
